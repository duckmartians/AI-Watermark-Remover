## Первый запуск

1. **Откройте файл.** Кнопка **📄** — выбрать один или несколько файлов, **📁** — открыть целую папку, или **перетащите** файлы в окно. Если у файлов разные пропорции, приложение спросит, какие загрузить (или все).
2. **Закрасьте водяной знак.** Выберите **Кисть**, **Рамку** или **Текст** в колонке инструментов; закрашенная область показывается **бледно-красным**. Закрывайте полностью и немного заходите за края — так лучше, чем недокрасить.
3. **Нажмите «Запустить».** Результат заменит закрашенную область. Если открыто несколько файлов, **«Запустить все»** применит ту же область ко всем файлам того же размера.
4. **Нажмите «Сохранить»** и выберите папку (приложение спрашивает каждый раз). Чтобы сохранить оригиналы, заранее включите **«Добавить _clean»**.

## Возможности

- **Кисть, рамка или текст** — свободно закрашивайте Кистью, растяните Рамку для быстрого покрытия, сотрите лишнее Ластиком, или напечатайте текст поверх текстового водяного знака, чтобы точно его закрыть. Текст — только метка: после обработки он исчезает и не впечатывается в изображение.
- **Правка выделения** — Отменить / Повторить, Очистить всю закрашенную область или вернуть Оригинал.
- **Пакетная обработка** — **«Запустить все»** применяет текущую закрашенную область ко всем открытым файлам с той же пропорцией; файлы с другой пропорцией пропускаются и подсчитываются в конце.
- **Удаление водяных знаков с видео (Pro)** — ИИ обрабатывает видео покадрово, работает только в области вокруг водяного знака, возвращает результат в исходный кадр и сохраняет оригинальный звук. Встроенный плеер позволяет просматривать ролик с качеством превью 100 / 75 / 50 / 25%.
- **Сохранение без перезаписи** — сохраните файл и перейдите к следующему, или **«Сохранить все»** обработанные файлы в одну папку; **«Добавить _clean»** добавляет суффикс к новым файлам (`photo.png` → `photo_clean.png`).
- **Офлайн и приватно** — всё работает на вашем компьютере, ничего не загружается в сеть.
- **9 языков интерфейса** — English, Tiếng Việt, বাংলা, हिन्दी, Português (BR), Русский, Türkçe, اردو, 简体中文 — переключаются значком глобуса.

## Инструменты и управление

### 📂 Открыть

**📄** открывает один или несколько файлов, **📁** — целую папку, или перетащите файлы прямо в окно. При нескольких файлах внизу появляется лента миниатюр — щёлкните миниатюру, чтобы переключиться, или **×**, чтобы убрать её из списка. Lite принимает только изображения; видеофайлы отфильтровываются.

### 🖌 Инструменты

| Инструмент | Для чего |
|---|---|
| **Кисть** | Закрашивать водяной знак (удерживайте левую кнопку и ведите). Размер — ползунком, `Ctrl` + колесо мыши или `[` / `]`. Удерживайте **правую кнопку**, чтобы стирать прямо во время рисования. |
| **Рамка** | Растянуть прямоугольник поверх водяного знака для быстрого покрытия. |
| **Стереть** | Убрать лишнюю закраску. |
| **Текст** | Напечатать текст поверх текстового водяного знака для точного покрытия (только изображения). `Delete` удаляет выбранный текст. |

Чтобы снять выбор инструмента, нажмите его кнопку ещё раз или **Esc**. **Отменить / Повторить / Очистить / Оригинал** находятся в той же колонке.

### ▶ Запуск

**«Запустить»** обрабатывает открытый файл; **«Запустить все»** (появляется при 2+ файлах) обрабатывает все файлы с той же пропорцией. Во время работы кнопки превращаются в **«Стоп»** / **«Остановить всё»**. Результаты хранятся в приложении, пока вы их не сохраните.

### 🎬 Видео (Pro)

Откройте видео, остановитесь на любом кадре и закрасьте водяной знак Кистью или Рамкой (начало рисования ставит воспроизведение на паузу). Кнопкой воспроизведения и полосой перемотки проверьте ролик, а меню качества (100 / 75 / 50 / 25%) облегчит превью. Видео обрабатывается покадрово, поэтому это **намного медленнее, чем изображения** — просто дождитесь. Затем сохраните его через **«Сохранить»** или **«Сохранить все»**, как изображение; на выходе — `.mp4`.

### 💾 Сохранение

**«Сохранить»** записывает текущий результат и переходит к следующему файлу; **«Сохранить все»** записывает все обработанные файлы в одну папку. Папку приложение спрашивает каждый раз. Включите **«Добавить _clean»**, чтобы добавлять `_clean` к имени вместо исходного имени.

### 🔍 Просмотр

Колесо мыши — масштаб, удерживайте среднюю кнопку и ведите — перемещение, **F** или двойной щелчок — вписать в окно. Значок **домика** открывает сайт; **глобус** меняет язык.

## Устранение неполадок

**Windows блокирует запуск: «Windows protected your PC»** — нажмите **More info → Run anyway**. Приложение не подписано платным сертификатом, поэтому помечается — это не вирус.

**macOS пишет, что приложение повреждено / не может быть открыто** — оно не подписано Apple. В первый раз — правый щелчок → **Открыть**, или выполните `xattr -dr com.apple.quarantine "/Applications/AI Watermark Remover Lite.app"`.

**Не открываются видео** — у вас редакция **Lite**, она работает только с изображениями. Установите **Pro** (Windows + видеокарта NVIDIA), чтобы удалять водяные знаки с видео.

**При сохранении сообщение, что видео экспортируется через «Запустить»** — это видео ещё не обработано. Сначала нажмите **«Запустить»** (или **«Запустить все»**), затем **«Сохранить»**.

**«Запустить все» пропустил часть файлов** — обрабатываются только файлы с той же пропорцией, что и файл, на котором вы рисовали. Откройте остальные отдельно или выберите их пропорцию при открытии.

**После удаления остаются бледные следы** — закрасьте полнее и немного за края водяного знака, затем запустите снова. На больших областях со сложным фоном следы всё же могут остаться.

**Видео обрабатывается очень долго** — это нормально: ИИ обрабатывает каждый кадр, поэтому видео занимает гораздо больше времени, чем изображения. Просто дождитесь; короткие ролики и видеокарта с большим объёмом VRAM справляются быстрее.

**Приложение закрывается само** — приложите файл `crash.log` (см. таблицу выше), когда сообщаете о проблеме.
